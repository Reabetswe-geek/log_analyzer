# Linux log analyzer

## Description
This project contains a Bash script that analyzes authentication logs on a Linux system

It provides:
-Number of failed login attempts
-Number of successful logins
-Top IP addresses attempting login

## Technologies Used
-Bash
-Linux command line tools (grep, awk, sort, uniq)

## How to Run

1. Clone the repository
2. Navihate into the project folder
3. Make the script executable

chmod +x log_analyzer.sh

4. Run the script

./log_analyzer.sh
